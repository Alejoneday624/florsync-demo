# FlorSync Demo — Frontend

Interfaz React de la demo. Instrucciones completas en el
[README principal](../README.md).

## Uso rápido

```bash
npm install
npm run dev
```

Abre http://localhost:5173 — necesita el backend corriendo en `http://127.0.0.1:8000`.

## Scripts

| Comando | Descripción |
|---------|-------------|
| `npm run dev` | Servidor de desarrollo con proxy a `/api` |
| `npm run build` | Build de producción en `dist/` |
| `npm run lint` | Verificación con ESLint |
